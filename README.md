# Лимиты - плагин Paseo

Версия 0.1.2. Строка под полем ввода с лимитами подписок Claude и Codex:
проценты, полоски, время до сброса и одна кнопка обновления. Нужны Paseo 0.12.0+
и работающий локальный поллер на macOS.

Плагин читает `/Users/agmazin/.multica/usage-limits.json` на стороне демона раз
в минуту. Сам Anthropic и OpenAI не опрашивает. Кнопка запускает существующий
LaunchAgent `com.agmazin.multica-usage-push` и ждёт новый `fetchedAt` до 30 секунд.
Если файл обновлялся или запуск уже запрашивали меньше минуты назад, только
перечитывает его. Все клиенты одного демона разделяют один запрос обновления.

Остаток времени пересчитывается каждые 30 секунд. После 10 минут без свежих
данных строка тускнеет и показывает время последнего снимка. Если файл временно
повреждён или недоступен, остаются последние корректные цифры, ошибка идёт в лог.
Провайдер без данных не показывается.

## Установка после приёмки

Основной Paseo включает оркестратор. Во время разработки используется только
отдельный тестовый демон. Плагины - доверенный код с доступом к файлам и процессам
демона; глобальный переключатель плагинов должен быть разрешён владельцем.

С 20.10.2026 основной Paseo грузит плагин не из этого каталога, а из отдельного клона
по тегу принятой версии: `/Users/agmazin/Library/Developer/paseo-releases/paseo-limits`.
Исполнители работают в этом каталоге на месте, и перезагрузка плагина из него подхватила
бы черновик. Первая установка:

```sh
git clone --branch v0.2.3 /Users/agmazin/Yandex.Disk.localized/public/projects/local/paseo-limits /Users/agmazin/Library/Developer/paseo-releases/paseo-limits
ln -s /Users/agmazin/Library/Developer/paseo-limits/node_modules /Users/agmazin/Library/Developer/paseo-releases/paseo-limits/node_modules
paseo plugin install /Users/agmazin/Library/Developer/paseo-releases/paseo-limits
paseo plugin ls
```

Проверить статус `running`. Перезапускать демон не требуется.
Для другого демона добавлять `--host 127.0.0.1:6783` ко всем командам.
Зависимости разработки находятся вне Яндекс.Диска; `node_modules` в репозитории
является симлинком на `/Users/agmazin/Library/Developer/paseo-limits/node_modules`.
Paseo предоставляет клиентские модули при загрузке плагина.

## Обновление и откат

Принятую версию отмечают тегом `vX.Y.Z` и переключают на него клон:

```sh
git -C /Users/agmazin/Library/Developer/paseo-releases/paseo-limits fetch --tags
git -C /Users/agmazin/Library/Developer/paseo-releases/paseo-limits checkout vX.Y.Z
paseo plugin reload paseo-limits
paseo plugin ls
paseo plugin logs paseo-limits
```

Откат - тот же `checkout` на прежний тег и `paseo plugin reload paseo-limits`.
При изменении зависимостей сначала обновить их в каталоге вне Яндекс.Диска.
Не выполнять `npm ci` поверх симлинка: менеджер может заменить его каталогом.
Для быстрого отключения: `paseo plugin disable paseo-limits`.

## Компактный вид и запасной вариант

Когда строка не помещается, полоски скрываются, подписи становятся "5ч" и "нед".
Стандартная ширина содержимого Paseo 820 px уже может потребовать этот вид;
в широком тесте настройка ширины содержимого равна 1100 px.

На телефоне и в компактном клиенте используется штатная пилюля над полем ввода.
Она же появляется у диалога, если метка поля ввода исчезла после обновления Paseo.
Нажатие открывает полный список с полосками и датами. Paseo ограничивает ширину
подписи пилюли и может обрезать её многоточием; полный текст и цифры доступны
в поповере. Отдельное приложение iOS/Android не запускалось, проверена компактная
web-раскладка 390x844 и совместимость исходников с React Native.

## Сервер компании

В контейнере задать PASEO_LIMITS_SOURCE=paseo. Плагин читает штатное providers.listUsage() Paseo 0.12.0, общий для всех сотрудников. Один запрос на процесс в минуту; Paseo дополнительно кеширует данные провайдеров. Передаются только проценты и время сброса. Имена аккаунтов, пути, токены и ошибки провайдеров в браузер не попадают. На одного провайдера должен быть настроен один аккаунт компании; несколько аккаунтов не суммируются. Нужны серверные OAuth-входы Claude и Codex, доступные служебному пользователю демона. CLIProxyAPI не предоставляет остаток исходной подписки.

PASEO_LIMITS_FILE задает путь к серверному JSON-снимку с прежней схемой. testData=true явно помечает тестовые цифры в интерфейсе. Это отдельный режим для стенда и внешних сборщиков, без запуска launchctl. Без переменных сохранен macOS-режим. Обновление в серверном режиме перечитывает общие данные и не меняет подписки. Просроченные данные сохраняют исходное fetchedAt. Проценты рядом с окнами показывают остаток, полоса - использование.
