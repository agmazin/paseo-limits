# Лимиты - плагин Paseo

Строка под полем ввода Paseo с лимитами подписок Claude и Codex: проценты, полоски, время до сброса и одна кнопка
обновления. Цифры берутся у единственного поллера на Маке, сам плагин провайдеров не опрашивает.

- Спецификация: `docs/spec.md`
- Прототип: `prototype/v1.html` (открыть в браузере)

Установка, обновление и откат появятся здесь вместе с первой версией.
