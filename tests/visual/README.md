# Изолированный визуальный стенд

Нужен отдельный демон Paseo 0.12.0 с web UI на 127.0.0.1:6783, pluginsEnabled,
пустым тестовым диалогом без запуска хода и своим home вне Яндекс.Диска.
Основной демон не использовать. Установить проверяемый плагин, проверить живые
данные, затем временно отключить его только на тестовом демоне.

`prepare.mjs EXTERNAL/visual-plugin` копирует клиент и создаёт отдельный плагин
`limits-visual`. Меняются только источник данных и тема, никакой production-код
не содержит тестовых переключателей. Обновление фикстуры задерживается на
1.5 секунды для снимка вращения, не вызывает launchctl.

В EXTERNAL сохранить `browser-state.json` отдельного headless Chrome с открытым
тестовым диалогом, тёмной темой и contentMaxWidth 1100. Установить тестовый плагин
и выполнить из репозитория:

```sh
PLAYWRIGHT_MODULE=/absolute/external/node_modules/playwright node tests/visual/capture.cjs EXTERNAL/evidence
```

Скрипт создаёт `fixture.json`, снимает по два PNG для каждого из шести состояний,
проверяет отступы 8/8, широкий и узкий режим, анимацию и отсутствие pageerror.
`measurements.json` хранит точные замеры. Кадры не масштабировать при объединении.
После проверки отключить визуальный плагин, включить production-плагин на том же
тестовом демоне и повторить проверку реальных данных, fallback и компактного вида.
Закрыть собственный headless Chrome и остановить только созданный тестовый демон.

С 0.1.1 отступы в capture.cjs измеряются по глифам (Range + TextMetrics),
а не по 20-пиксельному line box. Регрессия ширины и нижних отступов отдельно
покрыта tests/layout.cjs; живые размеры 1710/1280/980 - tests/live-layout.cjs.
Отчёт: docs/electron-layout.md.

## Актуальная проверка v2

`PLAYWRIGHT_MODULE=/path/to/playwright node tests/visual/v2.cjs EXTERNAL`
проверяет отдельный демон 6783 с включённым limits-visual и workspace "Проверка v2".
Перед запуском выполнить prepare.mjs. Скрипт пишет fixture.json только тестового
плагина, использует отдельный browser-state.json, фиксирует время и меняет размер
окна. Поля: 897, 855, 720, 560 и снова 897 px. Скриншоты и JSON: EXTERNAL/v2-evidence.
`capture.cjs` и прежний отчёт относятся к v1; `tests/layout.cjs` сравнивает
исторические a9cd2f8 и ce5ba6e для регрессии коррекции отступов.
