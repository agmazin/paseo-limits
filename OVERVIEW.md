# Лимиты

Показывает лимиты Claude и Codex под полем ввода: процент использования,
полоску и время до сброса. Одна кнопка обновляет данные для обоих провайдеров.
На компактном экране доступна пилюля с подробностями по нажатию.

Нужны Paseo 0.12.0+ и настроенный поллер `com.agmazin.multica-usage-push` на macOS.
Плагин читает файл `.multica/usage-limits.json` в домашнем каталоге пользователя
демона. Кнопка обновления запускает этот LaunchAgent через launchctl; собственных
запросов к Anthropic и OpenAI плагин не делает. Ключи и токены не читает.

Если данные старше 10 минут, видна их дата. При временной ошибке остаётся последний
корректный снимок. Если Paseo изменит метку поля ввода, вместо строки появится
штатная пилюля с теми же данными. Её длинная подпись может обрезаться хостом;
по нажатию доступны все окна лимитов.

На сервере поддерживает общий остаток подписок Claude и Codex через штатные источники Paseo 0.12.0: PASEO_LIMITS_SOURCE=paseo. Нужны серверные OAuth-входы компании; CLIProxyAPI сам остаток не передает. В браузер поступают только проценты и время сброса. PASEO_LIMITS_FILE позволяет читать снимок серверного сборщика. Тестовые снимки с testData=true имеют явную подпись. По умолчанию на macOS используется прежний сборщик.

В настройках "Лимиты" параметр "Скрывать штатный значок Usage" включен по умолчанию. Он скрывает только штатную кнопку в боковой панели веб-клиента, включая компактный вид. При отключении параметра или выгрузке плагина кнопка возвращается.

В портале компании может показывать личные окна с подписью "Мои лимиты". Доли сотрудников рассчитывает и ограничивает портал; плагин получает только личный снимок. Общий режим macOS сохраняется. Для серверной проверки квот PASEO_LIMITS_EXPORT_FILE задает закрытый от сотрудников файл общего снимка.
