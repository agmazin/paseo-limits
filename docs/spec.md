# Плагин Paseo "Лимиты" - спецификация v1

Утверждено Александром 20.10.2026 по прототипу `prototype/v1.html` (открыть в браузере). Вид переносится из
прототипа один в один: CSS прототипа - эталон, значения брать оттуда, не придумывать. Где прототип и текст
расходятся по поведению, прав текст.

## Зачем

Видеть лимиты подписок Claude и Codex постоянно, а не по клику на кнопку использования в левом нижнем углу Paseo
(окно "Использование"). В Multica такая строка уже есть, Александр к ней привык.

## Решения Александра (не пересматривать)

1. Строка под полем ввода в каждом диалоге, как в Multica.
2. Без пунктирной обводки и меток: в прототипе это была пометка границ вставки.
3. Одна кнопка обновления на все нейронки, самая левая в строке.
4. Отступы над строкой и под ней одинаковые и небольшие: от низа поля ввода до текста и от текста до низа окна
   по 8 px (разница не больше 1 px).

## Вид

- Порядок: кнопка обновления, "Claude", окно "сессия" (полоска, процент, "· 3ч 48м"), окно "неделя", вертикальный
  разделитель 1x16 px, "Codex", окно "неделя". Если данные устарели - справа "данные от 13:08".
- Шрифт 13 px. Имя провайдера - светлее подписей, вес 500. Подпись окна - `foregroundMuted`. Процент - `foreground`.
  "· 3ч 48м" - тусклее подписей.
- Полоска 80x6 px, радиус 3 px, трек `#2a2a2a`. Заливка и цвет процента: до 70% зелёный `#3f8f6a` (процент обычным
  цветом), 70-89% жёлтый `#c98a2e`, от 90% красный `#d9534f`.
- Узкое окно, когда строка не влезает: без полосок, подписи "5ч" и "нед".
- Наведение на окно лимита - подсказка с точной датой сброса: "Claude, сессия: 27% использовано, сброс сегодня в 17:10".
- Кнопка обновления: значок rotate-cw 15 px в квадрате 24x24, скругление 7 px, тусклая; при устаревших данных
  подсвечена фоном; во время обновления значок крутится.
- Окна: у Claude - сессия (5 часов) и неделя, у Codex - неделя. Провайдера без данных не показывать.

## Данные

- Источник - файл единственного поллера на Маке: `/Users/agmazin/.multica/usage-limits.json` (launchd
  `com.agmazin.multica-usage-push`, раз в 3 минуты, код `/Users/agmazin/Yandex.Disk.localized/public/projects/agmazin/tools/multica-usage-push/`).
  Формат: `{ claude: { windows: [{ windowSeconds, usedPercent, resetsAt }] }, codex: {...}, fetchedAt }`.
- Плагин читает файл на стороне демона (RPC) раз в минуту. Anthropic и OpenAI сам не опрашивает: при опросе из двух
  мест Anthropic отвечает 429, и одно из мест остаётся без цифр (грабля Multica).
- Время до сброса считается на клиенте и обновляется раз в 30 секунд.
- Данные устарели, если `fetchedAt` старше 10 минут.
- Кнопка обновления: `launchctl kickstart -k gui/$(id -u)/com.agmazin.multica-usage-push`, затем ждать новый
  `fetchedAt` до 30 секунд и перечитать файл. Если прошлое обновление было меньше минуты назад - только перечитать.
  Ошибка - без всплывающих окон: кнопка снова доступна, строка в `paseo plugin logs`.

## Где показывается

- Компьютер (Electron/web): строка встраивается в окно Paseo сразу под полем ввода (под элементом
  `[data-testid="message-input-root"]`), в каждом открытом диалоге, и переживает перерисовки Paseo (MutationObserver).
  DOM - только в `client/web.ts` с проверкой `Platform.OS === "web"`. Цвета берутся из темы Paseo.
- Если метки поля ввода нет (Paseo обновился и поменял вёрстку) - те же цифры показываются пилюлей над полем ввода
  (`addComposerPill`): текст "Claude 27% · 13% | Codex 5%", по клику поповер с полосками и датами сброса.
- Телефон (iOS, Android): сразу пилюля над полем ввода.

## Ограничения

- Не перезапускать демон Paseo (`paseo restart`, `paseo daemon restart`): это убьёт агентов, включая оркестратора.
- Не трогать окно Paseo Александра: не активировать, не кликать, не двигать. Страницы в его личном Chrome не открывать.
- Черновики в основной Paseo Александра не ставить. Отладка - на отдельном тестовом демоне со своим home вне
  Яндекс.Диска (`paseo daemon run --home /Users/agmazin/Library/Developer/paseo-limits/test-home`, свой порт, включённый
  веб-интерфейс) и в безголовом Chrome. Включать плагин в основном Paseo будет оркестратор после приёмки.
- `node_modules` вне Яндекс.Диска (симлинк на `/Users/agmazin/Library/Developer/paseo-limits/`).
- Тексты интерфейса на русском. Типографика везде, включая отчёт: только дефис "-" и прямые кавычки, без длинных
  тире, ёлочек, тильды и знака рубля.
- Правила плагинов - навык `/Users/agmazin/.claude/skills/paseo-plugin/SKILL.md`.
