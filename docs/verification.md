# Проверка 0.1.0 - 20.10.2026

Исторический отчёт. Приёмка Electron выявила ошибочный критерий отступов
по line box и преждевременное включение узкого вида. Исправление 0.1.1 и
новые измерения по видимому тексту: `electron-layout.md`.

AGM-29 готова к приёмке. Проверка проведена на отдельном Paseo 0.12.0,
127.0.0.1:6783, home `/Users/agmazin/Library/Developer/paseo-limits/test-home`.
Основной демон, его конфигурация, окно Paseo и личный Chrome не изменялись.

## Подтверждено

- `npm run typecheck`, 5 тестов логики и `git diff --check` проходят.
- Production-плагин на тестовом демоне `running`, в его логах только штатные
  загрузки/остановки, без исключений.
- Живой источник - файл поллера. Кнопка обновления изменила `fetchedAt`
  с `2026-10-20T11:28:04.426Z` на `2026-10-20T11:29:49.353Z`.
  Повторная проверка финального клиента: с `11:35:51.867Z` на `11:36:55.885Z`.
  Цифры в строке соответствуют файлу. Прямых запросов к провайдерам нет.
- Тесты покрывают общий запрос для двух клиентов, минутный cooldown, свежий файл
  после перезагрузки плагина, таймаут 30 секунд, ошибку launchctl, повреждение
  файла с сохранением последних данных, пороги цвета и истёкшее время сброса.
- Шесть состояний сопоставлены с настоящим CSS прототипа в масштабе 1:1.
  Везде отступы 8/8 px. Широкая строка 1100 px, узкая 628 px, полоски 80x6 px.
  В узком виде полоски скрыты, подписи сокращены. `pageErrors=[]`.
- На живом клиенте удаление метки `message-input-root` убирает строку и показывает
  пилюлю. По нажатию открываются все окна, полоски и точные даты сброса.
- Компактный web-клиент 390x844 показывает пилюлю, её нажатие открывает bottom sheet.
  Реальный iOS/Android не запускался. Ограничение ширины подписи задаёт сам Paseo;
  в компактном виде она обрезается, полный набор цифр виден по нажатию.
- Удаление вставленной строки имитирует перерисовку хоста: появляется ровно одна
  новая строка. Переключение между черновиком и диалогом не создаёт дублей.
- Светлая и тёмная темы проверены. Тексты и кнопка используют цвета темы.

проектах: agmazin и paseo-limits. Открытая заглушка была только в README плагина;

для установки не нужен.
